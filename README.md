# Сборы — PWA MVP

Минимальный прототип школьного приложения: профили, достижения, монеты и асинхронная схватка отрядов.

## Запуск

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173`.

Правила MVP: ход длится 3 минуты; пропуск хода не останавливает матч; ставка возможна только после подтверждения обоих отрядов; косметика не влияет на силу.
